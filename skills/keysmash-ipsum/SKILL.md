# Keysmash Ipsum

ランダムな英字列を「何かの打ち間違い」とみなして読み解き、ダミー文章を作る。lorem ipsum より意味があり、faker より予想外の文章になる。

ゆらぎ (語数・文字・区切り) は全部スクリプトが seed から決める。agent の仕事は **1 回の推測で文章を返すだけ**。考えた過程や説明を出力しないことで token と待ち時間を最小にする。

## 手順

### 1. keysmash を生成する

```bash
node ~/.agents/skills/keysmash-ipsum/scripts/gen.ts --count 3 --lang en
```

| オプション | 既定 | 内容 |
|---|---|---|
| `--seed <s>` | 現在時刻 | 同じ seed → 同じ文字列。再現が要るときは指定し、seed を報告に残す |
| `--count <n>` | 1 | 文の数 (1 行 1 文) |
| `--words <min-max>` | `4-9` | 1 文の語数。`1` なら文末記号なしの 1 単語 (ラベル・仮の名前用) |
| `--word-len <min-max>` | en `2-8` / ja `2-5` | 1 語の文字数 (ja は助詞を除いたかなの数) |
| `--layout qwerty\|uniform` | `qwerty` | en: qwerty = 隣接キーへ流れる手癖、uniform = a–z 均等。ja: qwerty = 頻度表 + 定番の並び、uniform = かな均等 |
| `--lang en\|ja` | `en` | ja はひらがなを直接生成し、かなの上で段・行・濁点のずれ、っ/ん の挿入、抜けを 10% 混ぜる。句読点は `、` `。` |
| `--seps <chars>` | `" ,"` | 区切り候補。先頭が 85%、残りで 15% を等分 |
| `--trace` | off | 各文の下に語ごとの中間データ (en: `·` 隣接 / `\|` ジャンプの経路、ja: ずらす前のかなとずれ方)。本文は trace 有無で同一。推測には使わず、デバッグや調整用 |

ユーザーが量 (「3 段落」「短めに」) しか言わなければ `--count` / `--words` に読み替える。言語指定がなければ en。

### 2. 打ち間違いとして読み解く

各行を「`lang` の文章をタイプしようとして打ち間違えたもの」とみなし、最ももっともらしい元の文を推測する。

- **語数を保つ (strict)**: 区切り 1 つ = 語の境界 1 つ。1 keysmash 語 → 1 語 (en) / 1 文節 (ja)。ユーザーが「自由に」と言ったときだけ意訳してよい。
- 綴りの近さ (同じキー・隣接キー・同じ文字数) を優先し、意味は後から整える。文法的に通る文にする。
- `,` `.` はそのまま句読点として残す (ja は `、` `。`)。
- ja: ひらがなの打ち間違いとして読み、かな漢字混じりの日本語にする。区切りの空白は文節の境界として使い、出力では消す。

### 3. 出力

既定 (`text`): 推測した文章だけを返す。前置き・推論・元の文字列は出さない。

```
Thanks for checking the quick brown notes.
```

ユーザーが対応関係を見たいとき (`map`): 1 文ごとに元の行と、語ごとの `keysmash → 推測` を 1 行で添える。

```
sjdf qiuck bwn nkes.
→ sjdf=such qiuck=quick bwn=brown nkes=notes
Such quick brown notes.
```

seed を指定された・再現が要るときは末尾に `seed=<s>` を 1 行添える。

## MUST NOT

- スクリプトを通さず自分で「ランダムっぽい」文字列を作る (seed で再現できなくなり、LLM の手癖で偏る)。
- 推測の過程を出力する (token の浪費。この skill の存在理由に反する)。
- 推測できない語をスキップして語数を減らす (strict のとき)。苦しくても最も近い語を当てる。
